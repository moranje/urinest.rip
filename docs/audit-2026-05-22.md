1 file changed, 2 insertions.

Added `.npmrc` and `.DS_Store` to `.gitignore`. This is a minor housekeeping change that prevents accidental commit of macOS filesystem metadata (`.DS_Store`) and npm authentication/registry configuration (`.npmrc`). The `.npmrc` entry is particularly relevant: if an `.npmrc` file were committed with registry tokens, it would be a credential leak. Proactively gitignoring it is good security hygiene.
